# Polka Dot Abstract

By Felipe Amorim Castelo Branco

[View this project online](https://github.com/artCBranco/cart253/pr/challenges/variables/polkadot)

## Description

A simple drawing board that varies the shape of the brush randomly and the color through the mouse position + a touch of randomity. Press SPACEBAR to save the illustration when you're done.
